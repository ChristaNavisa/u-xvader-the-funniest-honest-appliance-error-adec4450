# We Both Knew

The funniest honest error message an appliance could show: a toaster that
burnt the toast at setting 7 — the setting its owner chose — and says so in
its own flat, put-upon voice.

Entry: `Toast setting 7. I did what you asked. We both knew.` (52 characters, one line)

The joke is the toaster's honesty: it followed the owner's own setting, and
both of them knew what setting 7 does to bread.
